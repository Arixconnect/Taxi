# Taxi ’t Gooi

Conversiegerichte, volledig responsive onepage-website voor een lokaal taxibedrijf in ’t Gooi.

**Website:** https://arixconnect.github.io/Taxi/

De site wordt bij iedere wijziging op `main` automatisch gepubliceerd met GitHub Pages.

## Bedrijfsgegevens aanvullen

Zoek in `app/page.tsx` naar placeholders tussen blokhaken. Voeg de definitieve bedrijfsnaam, contactgegevens, chauffeurinformatie, reviews en voorwaarden toe vóór definitieve livegang.

## Afbeeldingen

Plaats de aangeleverde PNG-bestanden in `public/assets/images/` met de bestandsnamen die in de websitecode staan. Tot die tijd toont de site verzorgde visuele placeholders.

## Ontwikkeling

Gebruik `pnpm dev` voor de lokale preview en `pnpm build` voor de productiebuild.
